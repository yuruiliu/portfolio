# 小锐 · 个人作品集

一个简洁的个人作品集网站，用于展示个人介绍、技能方向与项目作品。使用原生 HTML、CSS 和 JavaScript 开发，无任何第三方框架或 UI 组件库。

## 功能特性

- **个人展示**：侧栏包含头像、姓名、角色介绍、主导航和技能标签
- **项目作品**：项目列表由数据文件动态渲染，展示项目简介、技术栈和完成时间
- **深浅色主题**：支持浅色 / 深色主题一键切换，选择通过 `localStorage` 记忆，刷新后保持
- **响应式布局**：兼容桌面端与移动端，移动端自动切换为上下布局
- **导航高亮**：滚动页面时自动高亮当前所在区块的导航项

## 技术栈

- 原生 HTML5 / CSS3 / JavaScript（ES6+）
- 无框架、无第三方依赖

## 运行方式

项目为纯静态页面，无需构建。

**方式一：直接打开**

用浏览器打开 `index.html` 即可。

**方式二：本地 HTTP 服务**（推荐，可避免部分浏览器对本地文件的限制）

```bash
# 在项目根目录下执行
python -m http.server 8080
# 或使用 Node
npx serve
```

然后访问 `http://localhost:8080`。

## 目录结构

```
lab04/
├── index.html          # 页面结构
├── css/
│   ├── style.css       # 基础样式（含深浅色主题变量）
│   └── responsive.css  # 响应式适配
├── js/
│   ├── main.js         # 页面交互逻辑（项目渲染、导航高亮、主题切换）
│   └── projects.js     # 项目数据
├── images/             # 项目图片（SVG）
└── profile.md          # 个人信息备注
```

## 维护说明

- 新增 / 修改项目：编辑 `js/projects.js`，在 `projects` 数组中增加或修改条目，页面会自动渲染。
- 主题配色：深浅色配色分别定义在 `css/style.css` 的 `:root` 与 `[data-theme="dark"]` 中，通过 CSS 变量统一管理。
